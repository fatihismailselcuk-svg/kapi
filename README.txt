Kapı GPS Test - iPhone PWA
1. GitHub'da public bir repo açın.
2. index.html, manifest.json, sw.js dosyalarını köke yükleyin.
3. Settings > Pages > Deploy from a branch > main / (root) > Save.
4. https://KULLANICI.github.io/REPO/ adresini Safari'de açın.
5. Paylaş > Ana Ekrana Ekle. Uygulamayı ana ekrandan açın.
6. Konum doğruluğuna izin verin; isteğe bağlı kapı koordinatlarını girin.
7. Takibi Başlat; ilk testte ekran açık, ikincide ekran kilitli 2 dakika deneyin.
8. Kilidi açıp uygulamaya dönün; CSV Dışa Aktar ile olayları inceleyin.
Not: Bu uygulama kapı açmaz. iOS kilitliyken web sayfasının çalışması durabilir; kayıtlardaki boşluklar bu etkiyi gösterir.
